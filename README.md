# Sistema Inmuno - Recordatorios de Vacunación

Sistema web para gestión y recordatorios automáticos de vacunación.

## ✅ Estado Actual
- Recordatorios funcionando y automatizados
- Correos automáticos configurados
- CloudPanel ejecutando el cron

## 📋 Configuración de Producción

**Comando CloudPanel:**
```
/usr/bin/php8.4 /home/uat-inmunoalerta/htdocs/inmunoalerta.abitech.dev/artisan schedule:run
```

## 📚 Documentación

La documentación completa está en la carpeta `docs/RECORDATORIOS.md`

## 🚀 Funcionalidades
- Gestión de recordatorios de vacunación
- Envío automático de correos de confirmación
- Notificaciones programadas (7, 3, 1, 0 días antes)
- Dashboard de administración
- Gestión de dependientes
